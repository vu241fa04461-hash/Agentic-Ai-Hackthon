# Stitch AI Multi-Screen Design Loop Matrix

This document defines the **Stitch AI Prompt Loop Matrix** for rapidly iterating on each screen of the **Urban GIS Pothole & Micro-Flooding Engine**.

---

## 🔁 Screen Design Specs & Stitch Prompts

### Screen 1: 🗺️ Dashboard & GIS Map (`dashboard_screen.dart`)
- **Stitch AI Contract**: High-density urban overview header, KPI cards grid with colored top border indicators, and a full-width GIS Leaflet map viewport.
- **Stitch Iteration Prompt**:
  > *"Refine the Dashboard screen with Stitch AI glassmorphic cards, live pulsing status badges for active potholes, and a floating quick-center button on the GIS map."*

### Screen 2: 📸 AI Vision Defect Inspector (`ai_inspector_screen.dart`)
- **Stitch AI Contract**: Focuses on defect capture and computer vision scanning. Features camera upload target, HUD scanner reticle overlay, auto-confidence gauge (94.6%), multi-factor score calculator, and SLA target recommendations.
- **Stitch Iteration Prompt**:
  > *"Generate a futuristic Stitch AI inspection view with camera viewport reticles, neon green confidence indicators, and a priority meter badge."*

### Screen 3: 📊 Infrastructure Analytics (`analytics_screen.dart`)
- **Stitch AI Contract**: Data visualization dashboard featuring defect category doughnut chart, severity distribution bar charts, and SLA risk breakdowns.
- **Stitch Iteration Prompt**:
  > *"Design a clean Stitch AI data visualization screen with responsive chart containers, metric summaries, and severity distribution cards."*

### Screen 4: 🛠️ Work Orders & SLA Tracker (`work_orders_screen.dart`)
- **Stitch AI Contract**: Municipal dispatch log featuring search bar, severity drop-down filter, status selector (Open, In Progress, Resolved), and CSV export button.
- **Stitch Iteration Prompt**:
  > *"Create a high-density Stitch AI data table with row hover effects, pill status selectors, and action buttons for work order dispatch."*

### Screen 5: ⚙️ Municipal GIS Settings (`settings_screen.dart`)
- **Stitch AI Contract**: Municipal configuration panel for setting default GIS map center coordinates, SLA response thresholds (Hours), theme color tokens, and exporting `stitch_design_tokens.json`.
- **Stitch Iteration Prompt**:
  > *"Design a Stitch AI settings screen with input sliders for SLA thresholds, coordinate preset chips, and a Stitch design token exporter."*
